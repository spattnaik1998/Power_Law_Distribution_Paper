# Beyond the Power Law

Replication code and data for **"Beyond the Power Law: Log-Normal Bodies, Pareto Tails, and
the Limits of Industry Statistics"** (Pattnaik, Jain and Pinsky).

The paper tests one proposition at three levels of aggregation, on two US censuses:

| Claim | Test | Result |
|---|---|---|
| The firm size distribution is a power law | Pareto against log-normal, interval-censored MLE, Vuong | **Fails.** Log-normal preferred in all 46 years, \|Z\| > 200 |
| Its upper tail is a power law | Threshold sweep, Clauset–Shalizi–Newman adapted to bins | **Holds.** Exponent 1.056 from 20 employees up |
| Value and profit are distributed by sector | Creation-versus-capture across 71 industries; shift-share | **Fails.** Correlation 0.009; between-sector term −6.38 pts |

Every number in the paper is emitted from a `findings/headline_numbers.json` payload by
`paper/tables/_regenerate_tables.py`. Nothing is typed into the manuscript by hand.

## Layout

```
common/
  stacklib.py            shared library: API fetchers with caching, one matplotlib theme,
                         key loading, findings serialisation
  LIMITATIONS.md         85 numbered limitations, L1.1 to L14.8, each stating what it
                         forbids the paper from claiming and what it permits

NN_idea_name/
  notebook/              the analysis, as a .py (jupytext percent format) and an .ipynb
                         with outputs as executed
  data/                  raw API responses, cached as CSV
  figures/               PNG and SVG, both generated by the notebook
  findings/              headline_numbers.json plus the CSVs behind each figure
  README.md              what the idea tests and against which source

paper/
  main.tex               the manuscript, MDPI/JRFM class
  references.bib         73 references, every DOI verified against the publisher
  tables/                one .tex fragment per table, plus the generator
  figures/               PDF and PNG pairs as used in the manuscript
  Definitions/           MDPI class files
```

Ideas 12, 13 and 14 are the ones this paper rests on and carry their full data, figures and
findings. Ideas 1 to 11 belong to a companion article and are included here as notebooks and
headline findings only.

| Idea | Question | Source |
|---|---|---|
| 12 | Has business dynamism fallen while concentration rose, and where? | Census BDS |
| 13 | What shape is the firm size distribution, and where does its tail begin? | Census BDS |
| 14 | Does an industry's scale predict the share of value it keeps? | BEA GDP-by-Industry |

## Running it

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # then add your own keys
jupyter lab                   # or run the .py files directly
```

Each notebook locates the repository root by walking up for `common/stacklib.py`, so it can
be run from its own folder or from the root. Fetches are cached to the idea's `data/`
directory; delete a cache file to force a refetch.

The API keys are free. Census and BEA are the two this paper needs; BLS and FRED are used by
the companion ideas.

### Reproducing the paper

```bash
python paper/tables/_regenerate_tables.py   # rebuilds every table from the findings payloads
cd paper && latexmk -pdf main.tex
```

`_regenerate_tables.py` reads the `findings/headline_numbers.json` of ideas 12, 13 and 14. If
a notebook is rerun and a number changes, the tables change with it.

## Method notes

Five decisions in this code are not obvious and are worth knowing before reusing it.

**Identifiers are discovered, never constructed.** Series and table identifiers are looked up
in each provider's own catalogue at run time and verified against wording specific enough to
exclude the wrong answer. An earlier version of this pipeline resolved a request for national
employment to a state-level series, because the search matched industry words in the title but
not geographic coverage.

**Partitions are recovered arithmetically and verified.** Both providers publish totals and
subtotals inside the dimension they belong to. Summing a BDS dimension as returned gives about
three times national employment; summing the BEA industry column gives 4.45 times GDP. The
firm-size and age partitions are recovered as the largest set of classes summing to the
published total in every year (`12b_repair.py`); the BEA industry tree is recovered by size and
then descended from GDP (`14_value_created_value_captured.py`). Both reconcile to under 0.005
per cent and both raise rather than warn if they do not.

**No estimator runs on real data before recovering a planted answer.** Simulated data is binned
exactly the way the real data is binned, and the estimator has to recover the parameter it was
given. Eight such checks are recorded in Table 3 of the paper.

**Grouped concentration indices are bounds.** Grouping can only reduce a Herfindahl or a Gini,
so every concentration figure here is a floor and only its direction is interpreted.

**Nulls are reported.** The value-added margin does not measure what it was intended to measure
and is withdrawn in the paper rather than quietly dropped; the whole-range Pareto exponent of
about 0.67 is reported as evidence of a failed fit.

## Data sources

| Series | Provider | Coverage | Endpoint |
|---|---|---|---|
| Business Dynamics Statistics | US Census Bureau | 1978–2023 | `api.census.gov/data/timeseries/bds` |
| GDP-by-Industry | US Bureau of Economic Analysis | 1997–2025 | `apps.bea.gov/api/data`, `GDPbyIndustry` |

Both providers revise. The cached CSVs in each `data/` directory are the extractions the
reported results were computed from; a rerun against the live API may differ.
